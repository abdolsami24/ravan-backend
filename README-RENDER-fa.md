# RAVAN — بک‌اند روی Render (رایگان، برای تست)
# RAVAN backend on Render (FREE tier, for TESTING — not production)

> **این چیست؟** این پوشه همان بک‌اند NestJS فاز ۴ است، آماده برای اینکه روی
> سرور رایگان Render اجرا شود. وقتی بک‌اند روی Render باشد، سه اپ وب
> (passenger / driver / admin روی boyscoding.com) به‌جای حالت دمو، به
> بک‌اند واقعی وصل می‌شوند.
>
> **What is this?** The Phase 4 NestJS backend, ready to run on Render's free
> tier. Once it is live, the three web apps on boyscoding.com connect to the
> real backend instead of demo mode.

> ⚠️ **این فقط برای تست است، نه برای سرویس واقعی.** پلن رایگان Render بعد از
> ۱۵ دقیقه بدون ترافیک **می‌خوابد** و اولین درخواست بعد از خواب حدود
> ۳۰ تا ۶۰ ثانیه طول می‌کشد تا سرور بیدار شود. برای سرویس واقعی بعداً VPS لازم است.

## قدم ۲ — در Render یک Web Service بساز

1. به **render.com** برو و وارد شو (یا با GitHub وارد شو).
2. روی **New +** کلیک کن و **Web Service** را انتخاب کن.
3. ریپوی `ravan-backend` را انتخاب کن و **Connect** را بزن.
4. Render فایل `render.yaml` را می‌خواند و بیشتر تنظیمات را خودش پر می‌کند.
   اگر از تو پرسید، این‌ها را بگذار:
   - **Name:** `ravan-backend`
   - **Runtime:** `Node`
   - **Build Command:** `npm install && npm run build`
   - **Start Command:** `npm run start:prod`
   - **Plan:** `Free`
5. **Create Web Service** را بزن. Render شروع به ساختن می‌کند (چند دقیقه طول می‌کشد).

## قدم ۵ — به Hostinger بگو Render اجازه وصل شدن به دیتابیس را دارد

> ⚠️ **هشدار مهم — فقط برای تست!**
> پلن رایگان Render **IP ثابت ندارد** — هر بار که سرویس بیدار می‌شود،
> ممکن است از یک IP دیگر وصل شود. پس برای تست، باید در Hostinger به
> **همه IPها** اجازه بدهی. این برای تست قابل قبول است، ولی برای سرویس
> واقعی امن نیست — بعداً که به VPS رفتی، این قانون را پاک کن و فقط IP
> همان سرور را مجاز کن.

1. به **hpanel.hostinger.com** برو → **Databases** → **Remote MySQL**.
2. در قسمت Access Host، بنویس: `%`
3. دکمه Add / Create را بزن.

`%` یعنی «هر IPای می‌تواند به دیتابیس وصل شود» — رمز دیتابیس هنوز لازم
است، ولی هر کسی که رمز را بداند می‌تواند از هر جایی تلاش کند. پس:
- رمز دیتابیس را قوی نگه دار و به کسی نده.
- وقتی تست تمام شد، قانون `%` را حذف کن.

## قدم ۶ — آدرس API را در سه اپ وب عوض کن و دوباره آپلود کن

1. در کامپیوتر خودت، در هر سه پوشه اپ، فایل `js/config.js` را باز کن:
   - `passenger/js/config.js`
   - `driver/js/config.js`
   - `admin/js/config.js`
2. این خط را پیدا کن و آدرس Render را بگذار:
   ```js
   API_BASE_URL: 'https://ravan-backend.onrender.com',
   ```
   (به‌جای `https://ravan-backend.onrender.com`، آدرس واقعی خودت را از قدم ۴ بگذار.
   حتماً `https://` باشد و آخرش `/` نباشد.)
3. سه فایل ZIP را دوباره بساز (یا فقط همان `js/config.js` را در File Manager
   جایگزین کن) و دوباره در ساب‌دامین‌ها آپلود کن:
   - `passenger.boyscoding.com`
   - `driver.boyscoding.com`
   - `admin.boyscoding.com`
4. حالا اپ‌ها را باز کن — بنر زرد DEMO باید **رفته باشد** و لاگین با شماره
   واقعی (`+17205550134`) باید با کد OTP واقعی کار کند.

> 💡 **نکته:** اولین بار که بعد از خواب سرور، اپ را باز می‌کنی، ممکن است
> لاگین حدود ۳۰ تا ۶۰ ثانیه طول بکشد (سرور دارد بیدار می‌شود). صبر کن و
> دوباره تلاش کن — بار دوم سریع است.

| موضوع | وضعیت |
|---|---|
| خواب بعد از بیکاری | بعد از **۱۵ دقیقه** بدون ترافیک، سرویس می‌خوابد |

| رم / CPU | ۵۱۲ مگابایت رم، برای بک‌اند تست کافی است |
| ساعت رایگان | ۷۵۰ ساعت در ماه — برای یک سرویس کافی است |

## عیب‌یابی

- **Build failed در Render:** به Logs برو. معمولاً یا Node version است
  (فایل `.node-version` با `22` در پوشه هست) یا یک فایل جا افتاده.
  مطمئن شو `package.json` و `src/` در ریشه ریپو هستند.
- **سرویس Live است ولی `/api/docs` باز نمی‌شود:** صبر کن — اگر سرویس خواب
  بود، اولین درخواست یک دقیقه طول می‌کشد. صفحه را رفرش کن.
- **خطای ۵۰۰ یا «Access denied for user»:** یعنی بک‌اند به دیتابیس وصل
  نمی‌شود. قدم ۳ (مقدارها درست است؟) و قدم ۵ (قانون `%` ساخته شده؟) را چک کن.
- **اپ‌ها هنوز بنر DEMO را نشان می‌دهند:** یعنی `API_BASE_URL` هنوز
  `localhost:3000` است یا آدرس Render اشتباه تایپ شده — قدم ۶ را دوباره چک کن.
- **OTP نمی‌آید:** در حالت تست، کد OTP در پاسخ API برمی‌گردد و خود اپ آن را
  نشان می‌دهد (همان‌طور که روی کامپیوترت دیدی). هنوز SMS واقعی وصل نشده.
